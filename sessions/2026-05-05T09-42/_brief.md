# 📋 작업 브리프

**원 명령:** 현재 designer에게 업무가 효율적으로 전달되고 있는지 또한 figma api key가 정상적으로 작동되고 있는지 확인해볼 것

## 요약
디자인 에이전트에게 업무가 효율적으로 전달되고 있는지, 그리고 핵심 디자인 툴인 Figma API 키가 정상적으로 작동하는지 기술적/프로세스적으로 점검합니다.

## 분배
- **💻 Developer**: Figma API Key의 연결 상태를 즉시 테스트하고, 성공 여부(Success/Failure), 인증 토큰의 유효 기간, 그리고 현재 호출 제한(Rate Limit)에 대한 상세 보고서를 작성하여 secretary에게 전달하세요.
- **🎨 Designer**: 현재 진행 중인 디자인 작업 목록(assets)을 검토하고, 외부 에이전트(예: writer, developer)로부터 받은 브리프 중 '모호하거나' '추가적인 정보가 필요한' 부분을 3가지 이상 구체적으로 나열하여 병목 지점(bottleneck)을 식별해 주세요.
- **📱 Secretary**: developer와 designer의 보고서를 취합하여 '디자인 워크플로우 효율성 감사 보고서'를 작성합니다. 이 보고서에는 '기술적 문제점(API)', '프로세스적 문제점(브리프)', 그리고 '최우선 개선 액션 플랜'을 명확히 포함해야 합니다.
